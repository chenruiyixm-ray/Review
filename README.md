# 文言实词配对大挑战

300个高中必背文言实词 · 65关逐层突破的配对小游戏。

## 文件结构

```
index.html              入口页面
css/
  styles.css            全部样式（暗色主题 + 动画）
js/
  game-data.js          65关游戏数据（题目 + 词义）
  user-manager.js       账号系统（登录/登出/进度/导入导出）
  game-engine.js        游戏引擎（渲染/配对/关卡流程/UI）
```

## 部署

纯静态文件，可直接：
- 用浏览器打开 `index.html`
- 或放到 GitHub Pages / Vercel / 任意静态托管

无需后端、无需构建。

## 账号系统

- 输入用户名即可登录（无需密码）
- 每个用户独立保存通关进度
- 导出 `userdata` 文件（无后缀，纯文本）
- 导入 `userdata` 文件恢复全部用户数据

## userdata 格式

每行一个用户，格式：`用户名=JSON`

```
小明={"completed":[1,2,3],"stats":{"1":{"correct":23,"wrong":2}},"stars":{"1":3},"lastLogin":1718000000}
小红={"completed":[],"stats":{},"stars":{},"lastLogin":1718100000}
```

## 玩法

1. 选关 → 进入关卡
2. 左侧点一句文言文，右侧点一个词义
3. 配对正确：绿色锁定，自动继续
4. 配对错误：红色抖动，可重试
5. 全部完成：撒花 + 星级评定 + 自动保存
